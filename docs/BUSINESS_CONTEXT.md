# Business context — vitalic-static-assets

<!-- Downstream of docs/ROADMAP.md — update that file first; this one follows. -->

This repository serves shared static assets for Vitalic Energy web properties:
brand SVGs that public-facing and internal sites embed directly by URL. Keeping
them in one public, version-controlled place gives every site the same artwork,
a review trail for changes, and automated checks that assets stay small, valid
and safe to embed.
